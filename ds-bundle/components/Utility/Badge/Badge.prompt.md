# Badge
## Classes
- `.badge` -- JetBrains Mono, 0.65rem, uppercase, 1px border, light bg
- `.filename` -- JetBrains Mono, 0.7rem, opacity 0.5
- `.timestamp` -- JetBrains Mono, 0.65rem, opacity 0.5

## Markup
```html
<span class="badge">Label</span>
<p class="filename">image.jpg</p>
<p class="timestamp">2026-01-01T00:00:00Z</p>
```
