# Typography

## Font stacks
- `var(--font-heading)` — Clash Grotesk. Display/hero text, headings, buttons, tabs.
- `var(--font-body)` — Instrument Sans. Body copy, descriptions, form inputs.
- `var(--font-mono)` — JetBrains Mono. Timestamps, filenames, badges, labels.

## Scale
`--text-xs` (11px) through `--text-5xl` (96px). Always use variables.

## Weights
`--weight-light` (200), `--weight-regular` (400), `--weight-medium` (500), `--weight-semibold` (600), `--weight-bold` (700).

## Common patterns
- Hero: Clash Grotesk, 4rem, uppercase, letter-spacing -0.03em, font-weight 700
- Section heading: Clash Grotesk, uppercase, 0.875rem, letter-spacing 0.1em, opacity 0.6
- Mono label: JetBrains Mono, 0.75rem, uppercase, opacity 0.6
- Body text: Instrument Sans, line-height 1.6
