# Dropzone

## Classes

- `.dropzone` -- 2px dashed border, centered text, radius-md, pointer cursor
- `.dropzone.is-dragover` -- teal border, teal-tinted background
- `.supported-formats` -- JetBrains Mono, 0.65rem, muted

## Markup

```html
<div class="dropzone">
  <p>Drop files here or click to browse</p>
  <p class="supported-formats">JPG, PNG, GIF, WEBP</p>
</div>
```
